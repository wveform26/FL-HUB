# FL HUB

Сообщество музыкантов FL Studio: треки, проекты, инструменты, плагины и драм-киты в одном каталоге. Можно слушать музыку прямо на сайте, скачивать паки, ставить лайки и обсуждать работы.

Проект полностью работает на стандартной библиотеке Python и не требует npm, сборки или внешних зависимостей. Фронтенд — vanilla JS (ES-модули), бэкенд — `ThreadingHTTPServer` + SQLite.

## Быстрый старт

Требуется Python 3.9+.

```bash
cd fl-hub
python3 server.py --demo
```

Флаг `--demo` создаёт базу и генерирует демо-контент: 8 авторов, 13 работ, обложки, WAV-треки, ZIP-паки со stems, MIDI и пресетами. Генерация занимает около 10–15 секунд. У демо-аккаунтов случайные пароли, поэтому войти под ними нельзя — для проверки входа зарегистрируйте свой аккаунт.

Без демо-контента (пустой каталог):

```bash
python3 server.py
```

По умолчанию сервер слушает `0.0.0.0:8000`. Откройте **http://127.0.0.1:8000** или адрес машины в локальной сети. Для доступа только с этого компьютера укажите `--host 127.0.0.1`.

Параметры запуска:

```bash
python3 server.py --port 9000              # другой порт
python3 server.py --host 127.0.0.1         # только локальный доступ
python3 server.py --demo                   # демо-контент, если база пуста
python3 server.py --reseed                 # удалить все данные и пересоздать демо
python3 server.py --lock-demo-accounts     # сменить пароли старых демо-аккаунтов
python3 server.py --secure-cookies         # cookie только по HTTPS
python3 server.py --trust-proxy            # доверять X-Forwarded-* от reverse proxy
```

Каталог данных по умолчанию — `data/` рядом с `server.py`. Его можно изменить переменной окружения `FLHUB_DATA_DIR`.

Пересоздать контент без запуска сервера:

```bash
python3 -c "import seed; seed.seed(force=True)"
```

## Перед публикацией

- Включите HTTPS на reverse proxy и запускайте сервер с `--secure-cookies --trust-proxy`.
- Старые базы, созданные до этой версии, могут содержать демо-аккаунты с общим паролем. Один раз выполните `python3 server.py --lock-demo-accounts` — команда сменит пароли демо-аккаунтов на случайные, сбросит их сессии и завершится.
- Логин ограничен 10 попытками за 5 минут с одного IP, регистрация — 5 попытками в час.
- Сессии живут 30 дней, хранятся в SQLite, cookie — `HttpOnly`, `SameSite=Lax`, с флагом `Secure` при `--secure-cookies` или HTTPS через `--trust-proxy`.
- Пароли хранятся как PBKDF2-SHA256 (210 000 итераций).
- Сделайте резервную копию каталога `data/` и не публикуйте его в git.
- Перед публичным запуском стоит добавить подтверждение email, сброс пароля и модерацию.

## Что умеет сайт

- **Каталог** с категориями, жанрами, тегами, поиском, сортировкой и пагинацией.
- **Страница работы**: обложка, описание, BPM, тональность, теги, комментарии, лайки, счётчики прослушиваний и скачиваний.
- **Плеер** внизу экрана: перемотка, громкость, очередь, Media Session, автоматический учёт прослушивания.
- **Загрузка** файлов до 180 МБ с прогрессом, drag&drop, необязательной обложкой и автоматической генерацией обложки, если её нет.
- **Профиль** с работами автора, редактированием описания и цвета аватара.
- **Регистрация и вход**, сессии на 30 дней, защита от CSRF для изменяющих запросов, ограничение попыток входа и регистрации.
- **Адаптивная вёрстка** для десктопа, планшета и телефона.

Категории и форматы файлов:

| Категория  | Что можно загрузить                          |
|------------|----------------------------------------------|
| Музыка     | WAV, MP3, OGG, FLAC, M4A                     |
| Проект     | ZIP, RAR, 7Z, FLP                            |
| Инструмент | ZIP, RAR, 7Z, SF2, WAV                       |
| Плагин     | ZIP, RAR, 7Z                                 |
| Драм-кит   | ZIP, RAR, 7Z, WAV                            |

Обложки: JPG, PNG, WEBP, GIF до 8 МБ.

## API

Все ответы — JSON, кроме медиа и страниц. Изменяющие запросы требуют заголовок `X-Requested-With: fetch`.

| Метод  | Путь                        | Назначение                          |
|--------|-----------------------------|-------------------------------------|
| GET    | `/api/me`                   | текущий пользователь                |
| GET    | `/api/stats`                | счётчики сообщества                 |
| GET    | `/api/authors`              | популярные авторы                   |
| GET    | `/api/items`                | каталог: `category`, `genre`, `q`, `sort`, `offset`, `limit` |
| GET    | `/api/items/:id`            | работа                               |
| GET    | `/api/items/:id/comments`   | комментарии                          |
| GET    | `/api/users/:username`      | профиль и работы автора              |
| POST   | `/api/register`             | регистрация                          |
| POST   | `/api/login`                | вход                                 |
| POST   | `/api/logout`               | выход                                |
| POST   | `/api/items`                | публикация работы (multipart)        |
| POST   | `/api/items/:id/like`       | лайк / снять лайк                    |
| POST   | `/api/items/:id/play`       | учёт прослушивания                   |
| POST   | `/api/items/:id/comments`   | добавить комментарий                 |
| PATCH  | `/api/me`                   | изменить профиль                     |
| DELETE | `/api/items/:id`            | удалить свою работу                  |
| GET    | `/media/covers/...`         | обложки                              |
| GET    | `/media/uploads/...`        | медиа с поддержкой Range             |
| GET    | `/download/:id`             | скачивание файла                     |

## Замечания

- Это компактный проект на стандартной библиотеке, а не готовый production-сервер: HTTPS обычно терминируется reverse proxy, нет подтверждения email, сброса пароля и модерации.
- Пароли хранятся как PBKDF2-SHA256 (210 000 итераций), сессии — в SQLite.
- Демо-контент генерируется программно: треки, сэмплы, MIDI и обложки создаются кодом, без сторонних файлов.
- Шрифты Unbounded и Manrope подключаются с Google Fonts; без интернета используются системные fallback-шрифты.
